Behavior spec

  • Column headers sort ascending; second click descending; third click clears.
  • Search matches name OR department, case-insensitive.
  • Department dropdown filters exactly.
  • Filters and search are additive (AND).
  • Page size 5/10/25; pager disables at boundaries.
  • "Select all" selects only visible page; count reflects total selected across pages.
  • Row selection persists across sorts/filters until row leaves the dataset.

Test ideas

  • Sort a numeric column vs. a string column — is the order correct?
  • Filter to 0 results — is the empty state handled?
  • Select rows on page 1, navigate to page 2 — does the count stay?
  • Change page size after selecting — does selection survive?
  • Keyboard: can you tab to a header and sort with Enter?
