Northwind Outfitters (buggy build)

Pixel-for-pixel the same storefront as the reference build. Seven rules are wrong, all of them about money, state, or a guard that is missing.

Testing charter — Work the money. Apply a discount and recompute every figure yourself. Cross the free-shipping threshold from both sides. Check out twice in a row and watch what the second order inherits from the first. The reference build is your oracle: any figure that differs between the two builds for the same actions is a defect.

    Payment

    Nothing leaves this page. There is no network here — the whole site runs with connect-src 'none'. Do not type a real card number anywhere, including practice apps.

    Behavior spec — what SHOULD happen

    • Tax: 8% of subtotal after discount.
    • Shipping: free over $50 after discount, else $5.99 flat.
    • Coupons are case-insensitive. EXPIRED is rejected.
    • Every money figure is rendered to two decimal places.
    • An empty basket cannot enter checkout.
    • Decrementing to 0 removes the line.
    • Placing an order clears the basket, the coupon and the coupon message.

    Answer key

    1. Tax computed on raw subtotal instead of discounted subtotal. Apply SAVE10 to $45 → tax should be $3.24 (8% of $40.50) but shows $3.60 (8% of $45).
    2. Free-shipping threshold uses raw subtotal, not discounted. Cart at $52 raw, HALFOFF applied → discounted $26, shipping should be $5.99 but shows FREE.
    3. Coupon comparison is case-sensitive. save10 is rejected as invalid; only uppercase works.
    4. Money not consistently rounded. The line total skips the formatter while every other figure uses it. Add 5× Gizmo: the line reads $29.950000000000003 and the subtotal below it reads $29.95.
    5. Empty basket can enter checkout and be ordered. With 0 items, Checkout proceeds and the order completes.
    6. "−" (decrement) can push qty below 1. The line stays in the basket at qty 0 instead of being removed at 1→0.
    7. Coupon not cleared after an order. The next order silently reuses the previous discount.
