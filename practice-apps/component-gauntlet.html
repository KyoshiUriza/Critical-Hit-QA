Every widget automation interviews ask about, on one page. Clean build — nothing here is deliberately broken.

Testing charter — automate one interaction per section below. Every control has a stable data-testid, so the exercise is the technique (frames, windows, waits, shadow roots), not hunting for a selector. The awkward ones are 6, 12, 13 and 16: alerts, frames, windows and shadow DOM each need something beyond a locator.
