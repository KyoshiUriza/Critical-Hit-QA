SQL Sandbox

Run real queries against a real dataset, in your browser. Graded on the result, so any correct approach passes.

What runs here. A small SQL engine supporting SELECT, JOIN / LEFT JOIN, WHERE, GROUP BY / HAVING, ORDER BY, LIMIT, the aggregates, and DELETE. Anything outside that subset returns an error rather than pretending to work. Nothing here touches a server — the dataset lives in memory and resets on reload.
