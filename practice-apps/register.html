Behavior spec

  • Full name: required, ≥ 2 chars, whitespace trimmed.
  • Email: required, valid format.
  • Age: required, integer 13–120. Under 13 = "Sorry, you must be 13+".
  • Country: required.
  • Password: min 8 chars, needs upper, lower, digit, symbol.
  • Password strength meter: weak / medium / strong.
  • Confirm must match password exactly.
  • Must accept TOS.
  • On success, form is disabled and a success message shown.

Test ideas

  • Emails: a@b, a@b.c, plus-addressing, unicode domain.
  • Age: 12, 13, 120, 121, negative, decimal, letters.
  • Password matching: paste vs. type, trailing whitespace.
  • Tab order and label associations.
  • Submit twice rapidly — double account created?
