File Upload

Drag-drop and click-to-pick file uploads with validation and simulated progress.

Drop files here or

Accepted: .jpg, .png, .pdf, .txt · Max 5 files · Max 2 MB each

Behavior spec

  • Accepts drop OR click-to-pick.
  • Max 5 files total in one batch.
  • Each file ≤ 2 MB (2,097,152 bytes).
  • Allowed types: .jpg, .jpeg, .png, .pdf, .txt.
  • Rejected files appear in the error list with a reason.
  • Upload button disabled until at least one valid file is present.
  • Each file gets its own progress bar (simulated, ~1.5s).
  • Uploading twice with the same set is idempotent (no duplicates).
  • Drop zone reachable and activatable via keyboard.

Test ideas

  • Drop a folder — what happens?
  • Rename .exe to .txt — accepted? MIME check?
  • Drop 6 files at once — is the 6th rejected or does the whole batch fail?
  • A 2 MB file exactly on the boundary.
  • Click Upload rapidly — does progress get confused?
