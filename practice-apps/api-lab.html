API Lab

Send requests against a REST API and read what comes back — status codes, error shapes, auth, idempotency. Six graded exercises.

No network is involved. The API runs in this page, which is why the lab works offline and why the site's connect-src 'none' policy still holds. Nothing here opens a socket.

Be clear about the trade: you are not practising HTTP itself — there is no DNS, no TLS, no real latency. You are practising the part interviews probe, which is knowing what to assert and why. When you move to a real client, only the transport changes.
