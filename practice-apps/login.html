Behavior spec (your oracle)

  • Email must be present, valid format.
  • Password must be present, min 8 chars.
  • Valid creds: demo@qa.test / Passw0rd!.
  • After 3 failed attempts, account is locked for 30 seconds.
  • "Show" password button toggles input type; button label updates.
  • "Remember me" persists last email in localStorage.
  • Errors are shown per-field and via role="alert".

Testable attributes

Every interactive element has a stable data-testid: login-email, login-password, login-submit, toggle-password, remember-me, email-error, password-error, login-result.
