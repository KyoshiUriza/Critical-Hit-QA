Your Profile

Create a profile to keep your progress separate from anyone else using this browser — and a sync code to carry it to another device.

How this works

This site is a set of static files with no server behind it, so there is nowhere to hold an account and nothing to log in to. Rather than build a login screen that only pretends to be one, profiles are stored in this browser and progress moves by a code you control.

  • Nothing is uploaded. No email, no password, no account to be breached.
  • Nothing is shared. Your progress never leaves this browser unless you copy a code out yourself.
  • It still works offline. Same as the rest of the site.

The honest trade-off: moving to another device is a deliberate act — copy a sync code and paste it there. There is no automatic sync, because that would need a server holding your data.

What is stored, exactly

All of it lives in this browser's local storage under keys beginning qaprep_. Clearing site data removes it. You can read the whole thing on the Progress page, which also exports it as a JSON file if you would rather keep a backup that way.

  • Quiz runs and per-category scores
  • Which seeded defects you have found
  • Study plan checkboxes
  • Bug report and test case drafts
  • Your daily streak

No analytics, no cookies, no third-party scripts. There is nothing here that reaches the network.
